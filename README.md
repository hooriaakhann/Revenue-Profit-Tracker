# Revenue & Profit Tracker 📊

## 📌 Overview
The "Revenue & Profit Tracker Dashboard" in Power BI provides a detailed analysis of sales performance, including profit, quantity, and order trends across categories and payment modes. Key metrics and visualizations empower stakeholders to monitor business performance, identify top-performing sub-categories, and track monthly profit trends.

## 🛠 Tools & Technologies
- Power BI
- DAX
- Power Query

## 📊 Key Features
- KPI Cards (Profit, Quantity, Orders)
- Monthly Profit Analysis
- Top Sub-Categories by Profit
- Category-wise Sales Distribution
- Payment Mode Analysis
